Use Inside Blender Asset Browser

Drop downloaded .blend files straight into your library or point Blender's remote/online asset catalog to your GitHub Pages index.

1

Download or Clone Repo

Download any individual .blend pack above, or clone the full GitHub repository containing the blender_assets.cats.txt catalog file.

2

Register Asset Library

Open Blender → Edit > Preferences > File Paths > Asset Libraries, click +, and select your downloaded folder (or paste the remote JSON URL in Blender 5.x).

3

Drag & Drop into Scene

Open the Asset Browser editor, choose your library from the dropdown, and drag models, node groups, or PBR materials straight into the 3D Viewport.
